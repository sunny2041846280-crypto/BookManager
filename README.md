图书管理系统 (Book Manager)

基于 C++ 单链表实现的简单图书管理系统，完成于数据结构《第二章 Project 作业》。

====================
项目简介
====================
图书馆需要管理一批图书信息，由于图书数量会动态增减，本项目采用带头结点的单链表作为存储结构，实现了图书的添加、查找、删除、显示和统计等功能。

====================
功能特性
====================
1. 初始化链表：创建一个带头结点的空链表。
2. 添加图书（尾插法）：追加到链表末尾，自动判断 ISBN 是否重复。
3. 按 ISBN 查找：精确查找并输出图书完整信息。
4. 按 ISBN 删除：正确断链并释放节点内存。
5. 显示全部图书：表格形式输出，使用 setw 对齐。
6. 统计信息：计算并显示图书总数、总库存、总价值。
7. 内存安全：退出系统前自动销毁链表，释放所有结点内存。

====================
技术栈
====================
语言：C++
数据结构：单链表（手写指针操作，未使用 std::list 等库函数）
IDE：Dev-C++

====================
文件说明
====================
main.cpp：主函数与菜单逻辑
book.cpp：单链表操作的具体实现
book.h：结构体定义与函数声明
BookManger.dev：Dev-C++ 工程文件
图书管理系统设计说明.docx：课程设计说明文档

====================
编译与运行
====================
方式一：使用 Dev-C++
1. 使用 Dev-C++ 打开 BookManger.dev 文件。
2. 按下 F11 编译并运行。

方式二：使用命令行 (g++)
g++ main.cpp book.cpp -o BookManager
./BookManager

====================
测试用例与输入格式
====================
添加图书时，请严格按照以下格式输入（逗号分隔，无空格）：
ISBN,书名,作者,价格,库存

测试数据参考：
978-7-111-1, 数据结构(C语言版), 严蔚敏, 45.00, 5
978-7-111-2, 算法导论, 科尔曼, 128.00, 3
978-7-111-3, 操作系统概念, 西尔伯查茨, 89.50, 2
978-7-111-4, 计算机网络, 谢希仁, 49.00, 8

====================
测试结果
====================
1. 显示全部：正确显示 4 本图书。
2. 查找图书：输入 978-7-111-2，正确返回《算法导论》。
3. 删除图书：删除 978-7-111-3 后，剩余 3 本。
4. 重复删除：再次删除 978-7-111-3，提示“未找到”。
5. 重复添加：添加重复 ISBN 978-7-111-1，提示“该图书已存在”。
6. 统计信息：删除后总数 3，总库存 16，总价值 1001.00。
